# 随机与计算系统 2.2.0

**Studio 2.0.0 兼容性说明：** 本次在编辑器和 Windows 独立播放器中发现宿主未提供项目数据库能力，使用候选表或函数规则表时会返回“当前宿主没有为数据依赖提供项目数据库能力”。修改前的 2.1.0 在同一宿主也复现，不能计为本次回归通过。JSON数组抽取池、范围随机和基础数学运算不依赖该接口；遇到此错误请使用JSON数组来源，表格和表函数需在宿主修复后重新验收。

一次抽取、批量随机、跨节点不重复抽取池，以及数学公式计算。扩展 ID：`mixing-entropy.random-math`，MIT 许可，无网络和原生依赖。

## 这次新增

- 持久抽取池：选项抽过后移除，下一次调用仍不会抽到；保存／读档保留相应时点的池。
- 两种方式：建池时洗牌后按顺序取出；或每次从剩余项随机取出，允许读档重抽。
- 数组：表或JSON数组建池，查看剩余数组；范围批量随机可以只输出JSON，无需逐项声明变量。
- 默认合并相同结果，也可明确选择按行区分。余量不足整批失败，不自动补满。
- 工坊说明直接包含完整用法，不依赖详情预览中的链接跳转。

## 按需求选方法

| 需要 | 方法ID |
|---|---|
| 整数／小数范围随机及数组批量 | `rand` |
| 文字权重抽取、单次或批量 | `rand-pick` |
| 数值／公式权重抽取 | `rand-pick-number` |
| 建立跨调用不重复池 | `deck-create` |
| 取出并移除项目 | `deck-draw` |
| 查看余量与剩余数组 | `deck-peek` |
| 删除指定池，准备新一轮 | `deck-reset` |
| 数学运算／表函数 | `calc` |
| 检查候选概率，不抽取 | `preview-pool` |
| 清除范围随机的固定结果 | `reset-fixed` |

## 三步开始

1. 建立独立命名池 `events`，来源JSON数组 `["调查","休息","交谈"]`，类型文字。
2. 每次需要选项时调用 `deck-draw`，同一池名，数量1；成功后读取文字结果和剩余数量。
3. 抽空走结束分支；新一轮先 `deck-reset`，再建立。不要在每抽前重复建池。

所有方法建议填成功开关和错误文本；失败保留旧结果，须先检查成功状态。`fixed` 要在建池之后保存才会保留顺序；读回建池之前仍会重建。`10%` 是固定概率，`10` 是相对权重，二者都不是保存结果的模式。
