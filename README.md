插件提供整数/小数随机、固定结果、批量抽取、列表权重和纯数学函数。运行时单入口，无网络或原生依赖；SDK、依赖锁文件未升级。

## 创作者快速使用

先在项目中声明结果变量：随机/计算用数值，列表/错误/概率报告用文本，成功状态用开关。调用方法的 Inspector 可选择结果变量、成功状态和错误说明。根据成功状态做条件分支，不能仅凭返回值 `-1` 判断错误，因为 `-1` 也可以是合法结果。

| 方法 ID | 用途 | 返回 |
|---|---|---|
| `rand` | 指定精度随机数；数量 2～100 时写入 `前缀_1..N` | 单次数值或批量数量，失败 -1 |
| `rand-pick` | 按当前变量计算权重并抽取候选 | 内容文本，失败空串 |
| `calc` | 基本运算或函数规则表计算 | 数值，失败 -1 |
| `reset-fixed` | 删除指定固定记录，下次重新生成 | 成功 true，失败 false |
| `preview-pool` | 不消耗随机数，检查候选、权重和概率 | JSON 文本，失败空串 |

成功时 `successVar=true`、`errorVar=""`；失败时 `successVar=false` 并给出原因。可预见的输入/配置错误不会覆盖原结果。结果、状态和错误变量不能重名；批量必须预先声明全部数值变量。异常 setter 会尝试恢复已存在的输出；SDK 不提供跨变量与存档的数据库事务，因此宿主自身写入故障不能承诺完全原子性。

## 随机数与存档

`digits=0` 抽整数，1～6 抽相应小数格点，每个格点等概率。例如 0～1、1 位小数可以得到 0、0.1…1，共 11 个值。包含端点开关对单次与批量都生效；1～3 且不含两端只能得到 2。反向范围、无可用格点、非有限数、非法数量/精度会报错。按精度放大后的端点绝对值不得超过 2^48。

- **每次重抽（fresh）**：每次抽取，允许重复。
- **首次抽取后固定（sticky）**：通过插件的槽存档记录结果；默认值 0 不再代表已生成。相同记录名复用相同结果，写到其他变量也可以。
- 自定义 `fixedKey` 为空时，单次记录名是 `value:结果变量名`，批量是 `batch:前缀`。没有输出变量时必须提供记录名。
- 修改有效格点范围、精度或数量后，旧记录报错而不会悄悄重抽；调用“重置固定随机”并填同一个记录名即可。重置不会清空结果变量。
- 记录跟随**当前存档槽**：读回生成后的存档保留结果；读回生成前的存档允许重抽。这不是跨存档防 SL，也不是可指定种子的随机序列。
- 已发布旧版本游戏要继承已有随机值时，显式选择“采用完整的既有结果”（`fixedPolicy=adopt`）。插件会验证全部值符合范围/精度；新游戏默认使用“首次生成，忽略输出默认值”。

## 候选表

绑定 `pickTable`，每行 `label` 是内容，`pool` 是池名，`weight` 可填数字或表达式。`field` 默认 label，`outIdVar` 可写入行 ID。

范围默认“指定池”：有名称时精确筛选，**空名称保留旧版全表行为**。要只取未命名的行，请选择“仅未命名池”；“全部池”明确取全表。

| 权重情况 | 行为 |
|---|---|
| 所有行都未填（含空白） | 均匀抽取 |
| 部分行填写 | 未填写的行按 0；正权重按比例抽取 |
| 全部为 0 | 默认失败；只有明确选择“均匀回退”才均匀抽取 |
| 负数、非法表达式、缺变量、非有限值 | 失败并指出原因，不自动解锁候选 |

5、2、3 对应 50%、20%、30%，短期不保证次数比例。动态例子：`var("观察") >= 50 ? 5 : 0`。先用“检查候选池与概率”查看报告；它也会检查输出列、权重、函数。上限 10000 行，超出报错，避免悄悄截断。查询范围为全表再筛未命名池时，上限仍作用于全表。

## 表达式与函数

`funcLib` 每行 name/expr，参数 x/y/z/w 缺省为 0。例如 `double=x*2`，`nested=double(x)+1`，计算 nested(3) 得 7。权重和计算共用同一套解析器，均支持嵌套表函数；函数保持无副作用，不能写变量或执行脚本。

支持 `+ - * / ^`、括号、比较 `< > <= >= == !=`、三元 `条件 ? 真值 : 假值`，以及 `sqrt`、`pow`、`floor`、`round`、`min`、`max`、`clamp`、`var("变量名")`。支持一元正负号与科学计数法；字符串仅可作为 var 的参数，缺失/非数值变量会报错，开关 true/false 转成 1/0。比较结果为 1/0，三元只计算所选分支。没有逻辑 &&/|| 或任意 JavaScript；不用 eval。

`2*3^2=18`，`2^3^2=512`，`-2^2=-4`，`2^-2=0.25`。这是相对旧版的重要修正，旧表达式如依赖原来的左结合行为，应增加括号。`round` 使用 JavaScript Math.round，恰好半数朝正无穷取整；`round(-1.5)=-1`。

函数名不可重复或覆盖内置名；缺函数、循环引用和过深调用会报错。函数表上限 1000 行，表达式 4096 字符、约 1024 token，解析深度 32，函数执行最多 4096 次调用。编译缓存最多 256 条；每次执行仍读取当前变量和当前表数据。函数库会整体校验，未被调用的坏规则也需要修正。

## 构建与回归

```powershell
.\Test.ps1
# 或分别运行：
npm.cmd run build
node node_modules/typescript/bin/tsc --noEmit
node --import ./_test/register-sdk.mjs _test/run-tests.mjs
node --import ./_test/register-sdk.mjs _test/repair.test.mjs
node _test/postbuild.test.mjs
```

开发环境使用 Node.js 24。在首次构建前运行 `npm ci --ignore-scripts`。统一入口包含 58 项基础测试、99 项边界与存档回归，以及 postbuild 回归。测试使用显式 SDK 适配器；这不替代目标宿主及导出游戏的集成验收。测试日志保留在本地，不属于发行包。

源文件 `src/index.tsx` 分成解析、输出校验、采样、存档、候选与方法定义；build 生成 `dist/index.js` 与相同内容的 `index.mjs`。watch 仅 tsc，交付前完整 build。发布包只需 extension.json、dist、assets，不含 sdk、node_modules 或夹具。

## 安装与检查

从本版本 Release 下载 `random-math-v2.0.0.zip`，使用 Studio 支持的扩展导入方式安装或更新。保留原项目与存档备份，确认扩展版本显示为 2.0.0，并检查两个数据绑定：`pickTable` 与 `funcLib`。

发行 ZIP 只含清单、运行代码、封面、许可证和面向用户的说明。GitHub 自动提供的 Source code ZIP 是源码包，需要构建。`SHA256SUMS.txt` 用于核对发行附件完整性。

插件仍使用 Math.random；允许连续出现相同结果，不是密码学随机源。本次没有改变宿主 SDK 或依赖版本。若宿主在复杂循环/存档定位时重放方法，每次重抽模式也会再次执行；需要保留抽取结果的事件请使用固定模式并验证实际流程。
