# 抽选与数学增强 3.0.0

**让剧本充满变数，让每次游玩都有独特体验**

**由原「随机与计算系统」升级而来。** 这是同一插件的3.0.0更新：沿用稳定ID `mixing-entropy.random-math`，旧调用继续兼容。已有工程升级前请先备份，迁移边界见下方说明。

![抽选与数学增强：动态抽取池、玩家选项、公式计算](docs/images/promo-300-hero.png)

为 LetsGal Studio 创作者提供抽取池、玩家选项、随机数与公式计算。把候选、条件和权重配置好，在剧情中抽取、选择或调整，让同一段流程产生更多变化。

[开始使用](docs/USER-GUIDE.md) · [离线手册](docs/creator-guide.html) · [安装 AI Skill](docs/AI-INTEGRATION.md) · [旧工程升级](docs/MIGRATION-3.0.md)

## 从一个池，组织多种可能

- **让概率随剧情改变。** 权重可以填写常量或数值变量公式；候选用布尔变量控制是否参与，筛选后按有效候选重新计算概率。
- **让有限机会有据可查。** 不放回池支持多份候选、两种计权方式和延后消耗；先占用，事件完成再确认，也可以取消释放。
- **把候选交给玩家。** 展示符合条件的选项，沿用工程现有 Choice 界面，布局可在官方 UI 编辑器中编排。
- **把计算留在剧情里。** 直接填写安全公式，完成取整、指定小数位、取模、大小比较与范围限制；结果写入变量供后续流程使用。

## 六个入口，各有用途

先选入口，再选操作；表单只显示当前操作需要的参数，可选执行反馈收进高级设置。

|入口|可以做什么|适合的场景|
|---|---|---|
|随机数|范围整数或小数、单次或批量、固定记录|自定义面数掷骰、数值波动|
|放回抽取|从指定池单次或批量抽取，候选保留|天气、重复可触发的随机事件|
|不放回抽取|按份数抽取、立即消耗或先占用后确认|有限奖励、事件队列、多份签池|
|调整抽取池|初始化、增删、启停、修改权重/概率/份数、批量调整、读取状态|随剧情推进改变机会与余量|
|玩家选项|展示合格候选并等待选择，输出候选 ID 与结果|可进入地点、可选择的行动|
|计算|算术、安全公式、表函数及常用数值处理|伤害、奖励、进度与循环数值|

不放回消耗的是**份数**：同一候选有多份时仍能再次抽中。显示文字相同的候选也可以使用不同 ID，分别管理。

## 看看怎么用

### 让天气倾向随变量变化

在“天气”放回池配置晴、阴、雨三个候选，把雨的权重写成 `var("降雨倾向")`。剧情修改该数值变量后，下一次抽取就会按新的权重计算。需要固定一段天气序列时，可选择“同一进度固定”。

### 先抽到事件，再决定是否消耗

用不放回池准备有限事件，抽取时选择延后消耗并保存凭证。玩家完成事件后确认消耗；放弃时取消占用。取消不会倒退随机进度，重复确认不会再次扣除。

### 让玩家从当前可行的行动中选择

“访问档案室”的候选条件填写布尔变量 `archive_open`。条件为假时不展示，为真时进入选项。选中后输出候选 ID，再由剧情分支安排后续内容。

### 一行公式得到数值结果

在“计算 → 直接公式”填写 `var("攻击") * 0.8 + 10`。攻击为 20 时，结果为 26；结果写入数值变量即可接后续流程。随机数范围设为 1～20 时也可以模拟二十面骰，不限于六面。

## 安装后，从一个小场景开始

1. 下载完整插件包，在 Studio 扩展管理中导入，并在目标工程启用“抽选与数学增强”。
2. 按手册声明输出变量；使用抽取功能时，在扩展设置中建立池与候选。
3. 在剧本中加入相应入口，选择操作并填写参数。需要处理失败、抽空或跳过时，在高级执行反馈中绑定状态，再使用本次结果。

已有作品先备份工程与升级前存档，再阅读[迁移与回退](docs/MIGRATION-3.0.md)。稳定插件 ID `mixing-entropy.random-math` 和原模块 ID 保持不变；旧调用继续兼容，迁移工具对能证明等价的调用提供预览、备份与转换。不能保证所有旧调用自动转换，也不保证新存档能降级读取。

## 随机策略与适用范围

允许读档重抽与同一进度固定可按玩法选择。固定池策略保存随机进度；读回建池前、修改条件或候选内容，不保证结果保持不变。“随机”也不保证连续两次一定不同。

主要验证环境为 Studio **2.4.0-beta.2** 与 Windows，具体操作和存读档覆盖见[验证说明](docs/VALIDATION-3.0.md)。Stable 完整版本尚未核定，Web / Android 尚未验证。

复杂条件可由外部系统计算为布尔变量；本插件管理抽取、选项和数值，不包含完整世界状态系统。
