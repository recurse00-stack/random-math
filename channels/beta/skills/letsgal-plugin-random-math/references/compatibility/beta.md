# Beta 资料与执行

资料修订 3.0.1；插件 3.0.1。当前资料参照 Studio 2.6.0-beta.1。官方 MCP 从该版提供；此前 2.3.0-beta.1、2.4.0-beta.1 / beta.2、2.5.0-beta.1 使用原工作流程。具体参数仍按目标完整版本、SDK 和真实样本，不从资料路由推定运行兼容。

MCP 未启用／未配置或旧版本不支持时简短回退；继续读 Beta 资料，不改装 Stable。MCP 可用且获准时按 ../mcp-workflow.md；pending / read-only / denied / 工具组关闭保留权限边界。断线不代表先前操作未提交，不盲目重做写入。

历史插件实机范围见 ../VALIDATION-3.0.md；MCP 工具可见、配置写入成功与播放／存读档／导出是不同证据。目标若为正式版，选择正式版载荷。只读选择器可报告 UNKNOWN；没有相关 SDK 时先做无版本依赖工作，不自动升级。
