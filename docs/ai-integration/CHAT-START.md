我使用LetsGal的抽选与数学增强，插件ID mixing-entropy.random-math，版本3.0.0。我提供了插件SKILL.md和本次相关参考文件，请先读取，报告实际读取到的文件与版本，再帮助编排。

核对目标工程实际启用的插件版本、Studio完整版本／通道、对应SDK和有效样本。仅加载匹配的Stable或Beta资料；未知或冲突标UNKNOWN，不默认选择最新版本，不升级引擎。

使用六入口：随机数、放回抽取、不放回抽取、调整抽取池、玩家选项、计算。作者配置与存档中的运行池分开；作者改配置不会覆盖已建池，但运行候选中的var("变量名")表达式会在每个抽取动作读取当前变量。剧情可通过调整抽取池增删候选、调整权重／概率／份数；插件不自动监听片段完成。复杂条件先由剧情或外部系统计算为布尔变量。

四项反馈在高级设置中展开；收起保留旧绑定及输出。抽取或选择后先检查status，再消费结果。参数意图不是可直接导入的章节节点；章节绑定、节点ID以该工程实际样本为准。
